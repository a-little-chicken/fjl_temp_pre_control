# V4 in-flight：100 个配对样本肉眼复核报告

## 结论

在同一批 100 个验证起点上，V4 与 V3 表现**混合、没有一致性提升**：V4 的样本 RMSE 在 47 个窗口优于 V3、53 个窗口劣于 V3；配对 RMSE 差值中位数（V4−V3）为 **+0.44℃**，意味着典型窗口略差。两版都常见高振幅波峰/波谷缩幅与时间错位；V4 的在途余热分量有助于呈现物理分解，但样本图中没有显示它稳定修复波形。

## 样本来源与口径

- V4 协议对应 3,302 个**开发验证**窗口，并明确 `test_inference=false`，不是独立测试集。
- 为公平比较，完全复用 V3 视觉复核抽取的同一批 100 个验证起点（时间戳逐点核验一致），起点间隔至少约 16 分钟。
- 黑线：未来实测温度；蓝线：V4 预测；绿虚线：同一样本的 V3 配对预测；红/橙虚线：950℃/880℃参考线。
- 分解图：V4 `disturb`、按训练得到的系数缩放后的 `hist_coal`、`closed_loop_coupling × forced`；第三面板显示真实未来煤量。
- 未来真实煤量被用作 Oracle 条件输入。图表是离线事后回放，不能代表在线预测或有效反事实。

## 100 个样本的摘要统计

| 指标 | V4 样本结果 |
|---|---:|
| RMSE 中位数 | 17.15℃ |
| RMSE 10%–90%分位 | 6.84–38.15℃ |
| RMSE 范围 | 2.85–61.69℃ |
| 端点绝对误差中位数 / P90 | 12.78℃ / 36.82℃ |
| P2P 比值中位数 | 0.807 |
| P2P 比值在 0.85–1.15 | 23 / 100 |
| 样本 RMSE ≤8℃ / ≤15℃ | 13 / 39 |
| V4 配对 RMSE 优于 / 劣于 V3 | 47 / 53 |
| 配对 RMSE 差值中位数（V4−V3） | +0.44℃ |

V4 全验证集汇总也未通过准入：加权 RMSE **23.96℃**、端点 RMSE **26.22℃**、P90 **37.63℃**、最大时距平均偏差 **6.94℃**、拐点 ±2 步比例 **47.0%**、P2P 比 **0.802**。这与样本复核中振幅压缩和拐点不稳的观感一致。

## 限制

100 个窗口只是验证集中的展示子集，且并非独立测试集；未来真实煤量是 Oracle 输入。不能据此声称 V4 在线性能、动作因果收益或闭环安全性。肉眼筛选典型图只能辅助诊断，整体结论应以全验证集、独立时间段和事件级配对评估为准。
