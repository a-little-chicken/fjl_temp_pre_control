- **对 `v2_meanbias` 预测张量（`validation_predictions.npz`）的深度解剖发现了两大核心根因，并已在 v3 代码中完成针对性改造（本地 18 项单测全部通过）：**
  1. **根因一：单点 `max-min` 振幅 Loss 与未锚定起点的差分项诱发“Step-0 脉冲作弊（Reward Hacking）”**：
     - 对 `validation_predictions.npz` 逐时刻剖析发现：`max_abs_horizon_mean_bias_c = 26.25℃` **并非发生在 15 分钟远端，而是发生在第 0 步（`t = +15s`）**！在 3,302 个验证窗口中，高达 **80.5%（2,658 个）的预测轨迹最大值出现在第 0 步**（真实轨迹仅 12.5%），第 0 步平均跳变高达 +26.84℃（RMSE 32.52℃，而真实 15s 温变仅 1.86℃），剔除前 3 步后真实预测峰峰值从 48.46℃ 跌至 37.97℃。
     - **机理原因：** 原 `p2p_p = max(pred) - min(pred)` 仅对窗口内单点极值回传梯度，且原一阶差分 `dp` 与二阶差分 `d2` 从索引 1 开始计算，**漏掉了 `t=0`（$\Delta T_0 \equiv 0$）到 `step 0` 的起点跨界差分**，加之 `step 0` 的时距权重最小（`w[0]=0.5`），导致网络学会在 `step 0` 制造 +26℃ 孤立尖峰以低代价骗取 P2P 指标；而仅约束窗口时间均值（`dim=1`）的 `mean_bias` 将整条曲线整体抬升了 +4.35℃，反而把 `step 0` 偏差从 +24.33℃ 推高到 +26.25℃。
     - **v3 代码修复：** ① 在 `dp` 与 `d2` 计算前显式补入起点锚定 $\Delta T_0 \equiv 0$（`F.pad(..., value=0.0)`）并加入 15s 最大温变势垒（`max_step_c=6.0℃`）；② 废除单点 `max-min`，改为**真实波峰/波谷软邻域相位对齐跨度（Phase-Aligned Soft Extrema Span）+ Top-$k$ 包络跨度 + 标准差匹配**；③ 解码器新增起点热惯性门控（`origin_gate`）与时距因果卷积混合器（`horizon_mixer`）；④ `mean_bias` 升级为 `50% 窗口时间均值偏差 (dim=1) + 50% 跨样本逐时刻系统偏差 (dim=0)`。
  2. **根因二：闭环负相关混杂（$\rho = -0.665$）与 Stage 1/2 顺序倒置导致 LPV 塌缩至边界及 Oracle 倒挂**：
     - **机理原因：** 历史闭环数据中 PID+DMC 控制器对温度上升作减煤动作，使 $\Delta T_{\text{forced}}(u_{t+1:t+H}-u_t)$ 与真实 $\Delta T$ 呈强负相关（$\rho = -0.665$）。对于任意仅依赖历史的因果分支 $\Delta \hat{T}_{\text{free}}(\mathcal{H}_t)$，叠加未来闭环煤量响应都会使误差方差膨胀 $\text{MSE}_{\text{oracle}} = \text{MSE}_{\text{direct}} + \text{Var}(\epsilon_F) + 2|\text{Cov}(\epsilon_Y, \epsilon_F)|$（实测 $\text{Std}(\Delta T - \Delta T_{\text{forced}})$ 从 32.39℃ 膨胀至 46.36℃）。原 Stage 1 将自由分支冻结在随机噪声并强行用 `forced` 拟合 `truth`，导致每一步梯度都将 $K_t$ 推向下限 7.5、$\tau_t$ 推向上限 280s；且原 `prior_loss` 漏掉了对 $\tau_t$ 和 `gain_calibration -> 1.0` 的约束，原 `calibrate_gain_scale` 存在以 $c=0$ 误差初始化 `best` 的逻辑缺陷。

## 一、 首轮训练表现与核心痛点剖析

根据 `model_1116/sa208_control_forecast_v1/` 在 sa-208 上的首轮训练与评估结果（验证集 3,302 个连续窗口），当前原型暴露了两个根本性问题：

### 1. 固定参数 FOPDT 先验与实际闭环数据严重失配（残差臂失效）
- **现象：** 采用经验先验（\(K=15\text{ }^\circ\text{C}/(\text{t/h})\)、\(\tau=200\text{s}\)、\(\theta=15\text{s}\)）构成的固定 FOPDT 动作响应，在验证窗口中产生的动作用煤贡献范围高达 \([-284^\circ\text{C}, +312^\circ\text{C}]\)（平均绝对贡献 27.3℃）。
- **后果：** 训练残差臂时，由于先验增益与物理实际不符，导致“自由响应分支”与“受迫响应分支”发生严重的特征冲突与梯度紊乱，残差臂验证加权 RMSE 高达 **48.69℃**（显著劣于直接基线）。
- **教训：** 在闭环反馈数据中，绝不能直接套用未经在线/离线辨识的“硬编码物理先验公式”叠加到深度网络中，否则会引入巨大系统误差。

### 2. 直接历史预测基线存在严重的“幅值坍缩（Amplitude Compression）”
- **现象：** 直接预测基线（无 FOPDT 动作输入）的验证加权 RMSE 为 **24.21℃**（端点 RMSE 26.82℃），虽然能够跟随大体趋势，但**预测振幅严重不足**（真实温度平均峰峰值 56.73℃，而模型预测平均峰峰值仅有 33.92℃）。
- **后果：** 模型为了追求总体均方误差最小，倾向于输出一条趋于平缓的“均值折中曲线”，无法准确预报极端波峰（\(\ge 950^\circ\text{C}\)）与波谷（\(\le 880^\circ\text{C}\)），无法满足控制器消峰填谷的安全需求。

## 二、 优化整改总体路线

围绕“能否为下游控制器提供具备控制可用性的早期瞬态轨迹”这一核心目标，后续整改将分三个阶段推进：

```text
[首轮原型诊断] ──► 1. 动作契约审计与 FOPDT 辨识校准
                        ↓
                 2. 双流解耦与状态自适应 LPV 架构升级
                        ↓
                 3. 面向控制的极值 Loss 与闭环准入验证
```

## 三、 分阶段整改实施细则

### 阶段一：数据动作契约审计与 FOPDT 动态辨识校准（第 1 周）

在盲目引入复杂的神经网络之前，必须先在离线数据上解开“闭环因果辨识悖论”：

1. **执行器数据与单位核实：**
   - 彻底核对 `feed_actual`（实际流量反馈）与 `feed_set`（给定）的物理单位、采样时钟及是否存在量纲缩放。
   - 采用突发阶跃段（避开平稳 PID 调节期），通过无参数系统辨识（如子空间辨识 Subspace Identification 或 IV法）重新标定真实工况下的边际增益 \(K\) 与纯滞后 \(\theta\)。
2. **状态自适应参数调制（LPV）：**
   - 废除“固定常数 FOPDT”，引入前面讨论的 **`StateAdaptiveCoalFOPDT`** 架构：利用历史编码上下文（隐含风煤比、氧量裕度或高负荷饱和状态），让 \(K_t\) 和 \(\tau_t\) 在安全物理区间（如 \(K \in [7.5, 22.5]\)）内随工况动态浮动。
3. **两阶段解耦训练流程：**
   - **Stage 1（物理锚定）：** 冻结神经网络，仅优化 LPV-FOPDT 的基准参数与饱和折减系数，确保残差基线合理。
   - **Stage 2（残差微调）：** 联合训练 PatchTST 自由响应分支与自适应 FOPDT 分支。

### 阶段二：模型架构升级——双流解耦与双通道切片（第 2 周）

首轮实现中，温度与尾煤特征被合并投影。整改中需严格落实**通道独立与跨通道注意力机制**：

1. **通道独立编码（Dual-Stream PatchTST）：**
   - 温度相空间特征（温度、一阶/二阶差分、希尔伯特瞬时相位）与尾煤/包络特征（煤量、阶跃脉冲、饱和计时器）各自通过独立的 Patch 投影与共享权重的 Transformer 编码器。
   - 防止尾煤阶跃的高频抖动直接污染温度波形特征。
2. **显式 Cross-Attention 因果检索：**
   - 让未来预测时刻（Query）去检索历史尾煤动作与温度瞬态（Key/Value），自适应捕捉 3~7 分钟的时变滞后时间。
3. **增量锚定预测输出（Delta Target）：**
   - 严守输出规范：\(\hat{T}_{t+k} = T_t + \Delta \hat{T}_{t+k}\)，确保预测起点与当前实测温度绝对无缝衔接，消除稳态静差。

### 阶段三：面向控制的 Loss 与量化准入验收（第 3 周）

彻底抛弃单一统计学 RMSE，建立以“控制可用性”为导向的 Loss 与指标体系：

1. **精简且强制的控制 Loss 设计：**
   - **远期加权 Huber：** 重点加保未来 8~15 分钟波峰到来的关键窗口。
   - **严格振幅匹配项（Amplitude Matching Loss）：** 显式加入 \(\mathcal{L}_{\text{amp}} = |\text{std}(\hat{Y}) - \text{std}(Y)| + |\text{P2P}(\hat{Y}) - \text{P2P}(Y)|\)，从数学上根除“曲线被拉平”的坍缩现象。
   - **红线越界重罚：** 对 \(\ge 950^\circ\text{C}\) 或 \(\le 880^\circ\text{C}\) 的极值点施加 5~10 倍平方误差惩罚。
2. **工业现场级准入 KPI 考核：**
   - **KPI-1（极值误差）：** 远端波峰/波谷绝对温差 \(< 6.0^\circ\text{C}\)。
   - **KPI-2（相位对齐）：** 拐点反转时刻误差 \(\le 2\) 步（\(\le 30\) 秒）。
   - **KPI-3（振幅还原率）：** 峰峰值比值在 \(0.85 \sim 1.15\) 之间。
   - **KPI-4（虚拟阶跃响应单调性）：** 人工将未来规划煤量 \(\pm 2\text{ t/h}\)，输出轨迹在死区后平滑张开且增益符号 100% 正确。
